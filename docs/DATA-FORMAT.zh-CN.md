# 行动台数据格式

[English](DATA-FORMAT.md) · [简体中文](DATA-FORMAT.zh-CN.md)

行动台从资料目录读取三个位置：

- `PROJECT.md`：事项和日历。
- `PROJECTS.md`：项目名称索引。
- `tools/desktop-action-desk/thread-links.json`：项目与Codex线程的对应关系。

文件使用UTF-8。`## 事项安排`、`## 日常安排`及中文分类名是当前解析格式的一部分，不随文档语言改变。

事项表按顺序包含九列：事项ID、事项/项目、分类、当前情况、下一行动、执行主体、交付物/依赖、真实期限/安排、来源。

每个事项只保留一行和一个稳定ID。ID使用16位小写十六进制，或`NNNN-A`加至少两位数字。单元格内的竖线写为`\|`。

“正在做”（In Progress）、“当前可做”（Ready）、“条件做”（Conditional）必须恰好选择一种，可额外标记“优先做”（Priority）。分类之间使用中文顿号`、`。

日历表包含日期、时间、事项、地点、状态、项目、来源和备注八列。日期使用有效的`yyyy-MM-dd`。事项截止日期不会自动变成日历安排。

配置中的`sourceDirectory`使用绝对路径，`chiefThread`填写自己的Codex主线程UUID。线程映射按四位项目编号关联已有线程。没有映射的事项返回主线程；演示UUID不能导航。

展示缓存不是任务数据库。修改缓存不会修改原清单，下次刷新会重新生成。当前日历时区固定为`Asia/Shanghai`。
