# 验证范围

本发布版在 Apple Silicon、macOS 27.0.1、Xcode 27.1 上独立构建。验证包括 Mac 宿主及两个扩展签名、版本与 AppIntents 元数据，Markdown 只读投影、分类、圆环命中/切换/日历、配置 URL 边界，以及遥测过期与未知字段。Linux 服务运行离线单元测试与回环接口检查；安卓构建及模型验证详见 android/README.md。

源码、包及最终 Release 附件检查私人身份/路径/网络和秘密特征，远端 tag/commit 与下载哈希须与本地产物一致。此范围不等于穷尽所有未知秘密。

未对本公开配置重复实测：另一台 Mac 的首次安装/WidgetKit 加载、真实对话跳转、完整多设备服务接入、安卓真机覆盖升级、长期后台/定时采集和网络路径。虚构示例不作为这些实测结果。构建与发布不安装现用软件、不重启服务或修改网络。
