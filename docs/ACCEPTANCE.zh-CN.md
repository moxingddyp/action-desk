# 行动台环境与已验证范围

[English](ACCEPTANCE.md) · [简体中文](ACCEPTANCE.zh-CN.md)

已在macOS 27.0.1、Apple Silicon和Xcode 27.1环境完成独立Release构建、本机签名校验和原生离线测试。

检查包括稳定事项ID、分类互斥、重复与非法数据、4000次偏好状态变换、1—34环段的命中区域与颜色邻接、事项展开与切换、日期和日历逻辑。示例清单包含4个虚构事项及2条虚构日历，另生成8张原生预览。

开源副本尚未完成独立新用户环境中的WidgetKit安装、权限和真实导航验收。未验证的系统和硬件不列为已支持范围。

1.0.1（构建16）已生成本地DMG及ZIP验收包，内含App、小组件扩展、多尺寸应用图标、虚构示例与中英文安装说明。两种包分别只读挂载/解压后，App文件逐项哈希与构建产物一致，签名完整性及容器检查通过；二进制的本机调试路径已移除，定向私人信息/凭据检查无命中。App依赖macOS系统框架，不依赖用户安装Xcode。

构建产物采用本机临时签名，没有Developer ID签名、公证或App Store分发。本机Gatekeeper安全评估明确拒绝当前验收包，不能记为默认安全检查通过；本地签名完整性通过不等于开发者身份获Apple认证。尚未验证另一台Mac通过互联网下载后的安装、首次打开和WidgetKit加载。用户已验收并批准按此状态发布1.0.1；普通用户安装与开发者源码构建已分开说明。
