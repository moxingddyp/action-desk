# 行动台环境与已验证范围

[English](ACCEPTANCE.md) · [简体中文](ACCEPTANCE.zh-CN.md)

已在macOS 27.0.1、Apple Silicon和Xcode 27.1环境完成独立Release构建、本机签名校验和原生离线测试。

检查包括稳定事项ID、分类互斥、重复与非法数据、4000次偏好状态变换、1—34环段的命中区域与颜色邻接、事项展开与切换、日期和日历逻辑。示例清单包含4个虚构事项及2条虚构日历，另生成8张原生预览。

开源副本尚未完成独立新用户环境中的WidgetKit安装、权限和真实导航验收。未验证的系统和硬件不列为已支持范围。

构建产物采用本机临时签名，没有Developer ID签名、公证或App Store分发。使用者自行准备环境并决定安装方式。
